## 🚀 Featured Projects

### 🏗️ End-to-End Sales Data Warehouse

**SQL Server · CRM & ERP Integration · ETL · Star Schema**

Designed and implemented an end-to-end Sales Data Warehouse using Microsoft SQL Server, integrating data from CRM and ERP source systems through Bronze, Silver, and Gold layers.

**Key features:**
- Built Bronze-layer ingestion processes using SQL and `BULK INSERT`.
- Developed Silver-layer transformations for data cleaning, standardization, deduplication, and quality validation.
- Designed a Gold-layer star schema with a Sales fact table and Customer and Product dimension views.
- Integrated fact and dimension objects using surrogate keys.
- Documented the data model, relationships, and column definitions in a data catalog.

`SQL Server` `Visual Studio` `ETL` `Data Warehousing` `Star Schema` `Data Modeling` `Git`
